# Spec Delta

## ADDED Requirements

### Requirement: 修饰键全程透明
系统 SHALL 保证 Ctrl、Shift、Alt 修饰键在脚本运行的全程保持透传：脚本 MUST NOT 拦截、抑制或改写任何修饰键事件；除 HOTKEY 本身外，脚本 MUST NOT 常驻拦截任何按键。速度模式激活期间，用户在按住任一修饰键（Ctrl / Shift / Alt）的同时拨动滚轮，系统 SHALL 将该滚轮事件按原生语义透传给当前应用（透传的合成事件 MUST 保留当时物理按住的修饰键状态），且 MUST NOT 将其吸收为速度调节。

#### Scenario: 非速度模式下 Ctrl+滚轮横滚
- **WHEN** 系统处于普通模式且用户按住 Ctrl 拨动滚轮
- **THEN** 当前应用收到带 Ctrl 修饰的原生滚轮事件，横滚（或应用定义的 Ctrl+滚轮行为）正常生效，脚本不产生任何合成滚动

#### Scenario: 速度模式下 Ctrl+滚轮旁路透传
- **WHEN** 系统处于速度模式且用户按住 Ctrl 拨动滚轮
- **THEN** 该滚轮事件被原样透传（保留 Ctrl 修饰），当前应用执行原生 Ctrl+滚轮行为，且当前滚动速度不因此事件改变

#### Scenario: 速度模式下 Shift+滚轮旁路透传
- **WHEN** 系统处于速度模式且用户按住 Shift 拨动滚轮
- **THEN** 该滚轮事件被原样透传（保留 Shift 修饰），不吸收为速度调节

#### Scenario: 速度模式下裸滚轮仍被吸收
- **WHEN** 系统处于速度模式且用户未按住任何修饰键时拨动滚轮
- **THEN** 滚轮事件被解释为速度调节（既有行为不变）

#### Scenario: 透传事件保留修饰键
- **WHEN** 速度模式下系统因修饰键旁路而转发滚轮事件
- **THEN** 转发的事件携带用户当时物理按住的修饰键组合，应用侧行为与未运行脚本时一致

### Requirement: 非速度模式零拦截
系统未处于速度模式时，MUST NOT 挂载任何滚轮事件钩子，滚轮事件（含任意修饰键组合）SHALL 以操作系统原生路径直达当前应用，脚本不经历"拦截再回放"。

#### Scenario: 普通模式下滚动滚轮
- **WHEN** 系统处于普通模式且用户拨动滚轮
- **THEN** 滚轮事件按原生语义传递给当前应用，脚本不产生任何合成滚动

#### Scenario: 进入速度模式后钩子生效
- **WHEN** 系统从普通模式进入速度模式
- **THEN** 滚轮事件开始被脚本拦截并解释为速度调节

#### Scenario: 退出速度模式后恢复零拦截
- **WHEN** 系统退出速度模式
- **THEN** 滚轮钩子被注销，滚轮立即恢复完全原生行为，无残留拦截

## MODIFIED Requirements

### Requirement: 滚轮事件映射为速度调节
速度模式激活期间，系统 SHALL 将**裸滚轮**（未按住 Ctrl / Shift / Alt）的向上/向下滚动事件解释为对当前滚动速度的调节，而不是直接转发等量的滚轮滚动：向下拨动 SHALL 增加向下滚动速度（或从向上速度中减速），向上拨动 SHALL 增加向上滚动速度（或从向下速度中减速）。速度模式期间，裸滚轮事件 MUST NOT 被按原生语义转发；按住修饰键时的滚轮事件不适用本要求，按"修饰键全程透明"要求旁路透传。

#### Scenario: 持续向下拨动加速
- **WHEN** 速度模式激活且用户未按修饰键连续向下拨动滚轮
- **THEN** 向下滚动速度逐步增大，页面以越来越快的速度向下连续滚动

#### Scenario: 反向拨动减速
- **WHEN** 系统正以某一速度向下滚动且用户向上拨动滚轮
- **THEN** 向下滚动速度减小；速度减至零后继续同向拨动 SHALL 使滚动反转为向上

#### Scenario: 速度为零时停止滚动
- **WHEN** 当前滚动速度为零
- **THEN** 系统不发送任何滚轮滚动事件，页面保持静止
