# Proposal

## Why

普通鼠标滚轮的滚动是"固定步长"的：想快速滚过很长的页面必须反复拨动滚轮，而精细滚动又容易过头。SpeedWheel 引入一种"速度调控模式"：进入该模式后，滚轮的滚动量不再直接映射为滚动距离，而是映射为持续滚动的**速度**（向上/向下），反向拨动则减速，从而实现类似"油门"的连续、可控滚动体验。

## What Changes

- 新增单文件 AutoHotkey v2 脚本 `main.ahk`，实现滚轮速度调控模式（speed mode）。
- 启动时读取脚本同目录下的 `.env` 文件：
  - `HOTKEY=`：触发速度模式的按键（AHK 热键语法字符串），未配置或文件不存在时默认为鼠标中键（`MButton`）。
  - `MODE=`：触发方式，`hold`（按住期间生效，松开立即退出）或 `tap`（按一下进入，再次按下退出），默认 `hold`。
- 速度模式激活期间：
  - 拦截滚轮上/下滚动事件，将其解释为对当前滚动速度的增/减（反向滚动即减速），而不是发送等量的滚轮事件。
  - 按当前速度与方向持续向系统发送滚轮滚动，实现匀速连续滚动。
  - 速度可减至零（停止滚动），反向继续拨动是否反转为反方向滚动由设计阶段确定并在规格中明确。
- 退出速度模式时立即停止一切由本脚本产生的滚动（杀停），恢复滚轮原生行为。

## Capabilities

### New Capabilities

- `wheel-speed-mode`: 速度模式核心行为——进入/退出（hold 与 tap 两种触发方式）、滚轮事件到速度的映射、持续滚动输出、退出时的杀停。
- `env-configuration`: `.env` 配置文件的读取与解析——`HOTKEY` 与 `MODE` 的取值、默认值、非法值的容错处理。

## Impact

- **代码**：`main.ahk`（当前仅有 `#Requires AutoHotkey v2.0` 头，为全新实现）。
- **运行环境**：Windows + AutoHotkey v2.0；需要以管理员或标准权限运行（拦截并发送滚轮事件使用 AHK 原生热键与 `Send`，无额外依赖）。
- **配置**：新增 `.env` 文件（用户创建），脚本需容忍其缺失。
- **系统行为**：速度模式激活期间，滚轮事件被本脚本接管；其他应用收到的滚轮输入来自脚本的合成事件。
